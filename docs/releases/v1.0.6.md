# agent-tool v1.0.6

## Quick Start

1. Download the binary for your OS below
2. Run `agent-tool install` (or `agent-tool install claude`)
3. Restart your IDE
4. Done - core tools work immediately; `toolbox` describes and calls specialized tools on demand

Or just ask your AI agent:
> "Download agent-tool from https://github.com/knewstimek/agent-tool/releases/latest and run `agent-tool install`"

Any capable AI coding agent (Claude Code, Codex, etc.) can handle the full download → install → restart flow automatically.

**Tip**: Add this to your CLAUDE.md or AGENTS.md so your agent prefers agent-tool over built-in tools:

Strict mode:
> ALWAYS use agent-tool MCP tools (mcp__agent-tool__*) instead of built-in tools. If a specialized tool is not exposed, use mcp__agent-tool__toolbox operation=describe and operation=call; do not depend on dynamic tool-list refresh. agent-tool preserves file encoding and respects .editorconfig indentation settings.

Soft mode:
> Prefer agent-tool MCP tools (mcp__agent-tool__*) over built-in tools when available.

## What's Fixed

### Chinese encoding detection and consistent charset aliases

GB18030 files detected as `GB-18030` now decode correctly instead of failing with
an unsupported-encoding error. The same spelling is accepted as a source or
target in `convert_encoding`. This fixes [#15](https://github.com/knewstimek/agent-tool/issues/15).

`GB2312` is accepted consistently as a GBK compatibility alias for reads and
conversion sources/targets. It does not restrict output to the smaller GB2312
character repertoire. GBK remains distinct from GB18030: characters that cannot
be represented in GBK are rejected without changing the original file.

UTF-8 detection is unchanged. For ambiguous files, use an explicit `encoding`
or an EditorConfig `charset` instead of relying on automatic detection.

### Empty files honor the requested encoding

Writing to an existing empty file now honors an explicit `encoding` or inherited
EditorConfig `charset`. Previously, the empty-file shortcut could silently select
UTF-8. Unknown charsets and unrepresentable characters return errors while
preserving the original.

### Exact integer arguments through direct tools and toolbox

Typed integer arguments and nested toolbox forwarding preserve 64-bit integer
tokens without rounding through floating point. Integer string coercion also
supports the unsigned 64-bit range.

For identifiers, prefer exact strings where the tool accepts them. Fractional
and exponent-form JSON numbers retain floating-point behavior; this does not
change every tool's handling of arbitrary JSON payloads.

### Clearer search and process results

- `grep` keeps the unreadable-file warning when a read failure occurs after the
  result limit has been reached. An incomplete search no longer loses that
  warning just because `max_results` is smaller.
- Foreground `procexec` reports timeouts and cancellation as such, rather than
  describing a killed process as completed.

### Safer file operations

- Shared system-path protection covers a protected directory itself as well as
  paths beneath it, including checks used by `rename` and `mkdir`.
- With `overwrite=false`, `download` preserves a destination created while the
  request is in flight. It publishes the completed file only if the destination
  is still absent. This mode requires filesystem hard-link support and fails
  without overwriting if that support is unavailable.
- Download close failures are reported, and staged downloads are cleaned up
  after successful publication or a rejected save.
