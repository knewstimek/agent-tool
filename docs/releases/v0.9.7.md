# agent-tool v0.9.7

This release reduces the model context required by a large MCP tool surface while adding safer
bulk file cleanup and substantially stronger static instruction and reference search.

## Highlights

- Adds an opt-in `core-lite` profile exposing five frequently used schemas and the on-demand
  `toolbox` gateway. Measured MCP tool-list size is approximately 6.4 KB for `core-lite`, 15.1 KB
  for the default `core` profile, and 85 KB for all 55 tools.
- Adds operation-scoped compact schemas and deterministic schema handles for common remote, data,
  file, Windows, and binary-analysis operations.
- Adds semantic x86/x64 instruction search by mnemonic, register, immediate value, call target,
  and finding kind, with bounded control-flow-aware value propagation.
- Expands x64 RIP-relative reference discovery and adds inclusive address-range searches.
- Adds guarded recursive directory deletion and bounded batch deletion for up to 100 explicit
  targets, including dry-run previews and protected-root checks.
- Makes `grep` and `glob` honor root `.ignore` files alongside `.gitignore`.

## Compatibility

- No breaking MCP tool names or required startup changes.
- Existing `core`, `coding`, `remote`, `analysis`, and `full` profiles remain available.
- Clients that keep fixed tool bindings can continue to discover and invoke non-core tools through
  `toolbox describe` and `toolbox call`.

## Verification

- The release workflow runs the Go package tests before building.
- Release assets are cross-compiled with `-trimpath` for Linux amd64/arm64, macOS amd64/arm64, and
  Windows amd64.
- Published assets include `SHA256SUMS.txt`; the workflow downloads and verifies the uploaded bytes
  before completing.

## Known limits

- Operation-scoped compact schemas cover common operations; other tools use the generic compact
  schema or their full input schema when described.
- Dynamic direct-tool exposure depends on whether the MCP client applies `tools/list_changed`;
  the `toolbox` gateway does not depend on that behavior.
