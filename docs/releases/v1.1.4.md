# agent-tool v1.1.4

## Quick Start

1. Download the binary for your OS below.
2. Run `agent-tool install` (or `agent-tool install claude`).
3. Restart your MCP client. Use `toolbox` for specialized tools.

## What's New

### Encrypted connection profiles

AgentTool can store SSH/SFTP, MySQL, Cloudflare, and AWS credentials in an
encrypted local vault. Use `profile_search` to find a profile by name, alias,
description, or tag, then pass its `connection_profile` to the matching tool.
Cloudflare and AWS profiles use `httpreq` with `profile_kind`.

- Run `agent-tool vault import-ssh` to copy legacy SSH profiles under new names
  ending in `-vault`. The original JSON and key files are kept.
- The vault opens automatically with its local key by default. To require a
  passphrase, create it with `agent-tool vault init --passphrase`.
- Search shows vault entries first. Set `storage: "vault"` to return encrypted
  profiles only. A readable catalog still returns results with a warning if
  another configured catalog is unavailable.

See `agent_tool_help(topic="tools/credential_vault")` for registration, key
rotation, and revision history.

### Instruction search can be paged or grouped by function

`analyze(operation="instruction_search")` reports total matches and defaults to
a 32,768-character page. Reuse the displayed `result_offset` with the same
filters to continue. Set `group_by_function=true` to see one row per function
with its address and match count. Partial analysis is
marked when tracing reaches its analysis limit.

## What's Fixed

- An SSH/SFTP connection ID is rejected if its vault connection settings have
  changed. Request a new ID using `connection_profile`.
- HTTP changes are no longer replayed after an ambiguous ECH transport error.
- Decompilation uses less memory when inferring callee floating-point return
  types and leaves the type unspecified if inference is incomplete.
- `decompile-all` retries failed entries when resumed, so a new timeout can
  take effect. It also ignores a result line cut off by an interrupted run.
- Exported data addresses are excluded from function enumeration.

## Compatibility Notes

- Keep the local vault key private. Restoring an automatic vault requires both
  the database and its matching key file. The two files together allow
  decryption.
- Existing SSH/SFTP profile names still work. Import leaves legacy credentials
  in their original files.
